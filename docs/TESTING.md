# 测试与验收

## 单元测试（无硬件）

```sh
python3 -m unittest discover -s tests -v
```

35 项：
- `test_protocol.py`：三个独立写入的精确字节、未填充 payload、原始分段续读、非法回复头、E 错误、命令边界、短写、setter 无读取。
- `test_control.py`：空回复=忙、孤立 `R` 跳过、功能别名（FREQ/FREQUENCY、RESISTANCE 等全称）、过量程（9.9e37 与 -8.888e3）与不可解析读数、SI 格式化；功能切换期间的 E、丢弃 setter 的重发、`R` 不触发重发、量程/分辨率读回与越界、读回失败、读数期间功能变化、期望功能、过量程读数、触发检查、状态；电阻全称回复与 0–5 档、错位回复不致命；错位回复不触发重发；采样器宽限期、错位回复按忙处理、迟到的量程索引不当作读数、采集中切到单次触发、拒绝保持读数、统计；CLI demo 写 CSV 与拒绝覆盖、参数在任何设置前校验、CSV 关闭失败仍释放设备、`--demo --list` 被拒绝。

GUI 用 Xvfb 驱动按钮/下拉框做过模拟与真机自动化测试（0.2.1 另测模拟：连接时仪器忙后恢复、采集中切到单次触发并用按钮切回、自动量程提示、电阻/通断切换）（脚本未纳入仓库，因为依赖桌面截图工具）。

## 验收清单（新环境/新固件请重做）

1. `sh run.sh --list` 恰好看到目标设备；多个设备时明确 bus/address。
2. `sh run.sh --status` 返回真实 DM3051、固件、当前功能、量程、分辨率、触发。
3. CLI 10 点采样，CSV 一行表头 + 10 行，数值与面板在显示精度内一致。
4. GUI 连接、切换功能/量程/分辨率均显示“已确认”，面板同步变化；面板手动切换时 GUI 跟随。
5. 停止后无新点，保存 CSV 记录数与缓存一致；实时记录文件与导出一致。
6. 插拔断线后停止并显示错误，已有数据仍可导出；重插后重新开始成功。
7. 两个应用同时访问不应伪装成功；关闭后内核驱动可重新接管。
8. 过量程显示 OVLD 而不是数值；单次触发下拒绝采样。
9. 无权限时明确失败；启用规则后普通用户成功。
